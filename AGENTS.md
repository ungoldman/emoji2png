# Agent Guidelines

- build: `swift build`
- test: `swift test`
- coverage: `swift test --enable-code-coverage`

Versioning and releases are handled by the maintainer via git tags. Do not create or change version tags.

Follow all coding and commit conventions in `CONTRIBUTING.md`.

Omit AI attribution in commits (Co-authored-by). Polluting git history with AI advertising is not allowed.
